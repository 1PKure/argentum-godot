# Arena scenery

Original SVG artwork for this prototype: cactus, weathered sandstone, carved stone column, basalt cluster, standing torch, volcanic brazier and pine.

The artwork uses a common upper-left light direction, restrained colour palettes and small contact shadows. `ArenaScenery` renders each at an explicit AO-scale size with its ground contact at the node origin. Flames are drawn separately so that the solid prop does not move or change collision size.

These assets were created specifically for this project; they do not introduce external downloads, paid dependencies or third-party attribution requirements. Collision and line-of-sight remain controlled by the server arena catalogue.
